# Segundo diseño

## 1. Resumen del problema 

Objetivo: entrenar un modelo lineal

$$y_{pred} = wx + b$$

sobre un dataset:

$$\{(x_i, y_i)\}_{i=1}^m$$

usando descenso de gradiente con tasa de aprendizaje $$\eta$$, donde las actualizaciones son:

$$dw = \frac{2}{m} \sum_{i=1}^m (wx_i + b - y_i)x_i$$  

$$db = \frac{2}{m} \sum_{i=1}^m (wx_i + b - y_i)$$  

$$w \leftarrow w - \eta \cdot dw$$  
$$b \leftarrow b - \eta \cdot db$$  

*Core concern (responsabilidad principal):* implementar el bucle de entrenamiento (forward, cálculo de gradientes, actualización de parámetros, control de epochs).

---

## 2. Principio AOP aplicado

Separar código en:

- *Módulo central/servicio de entrenamiento (core):* contiene la lógica matemática y el flujo principal.  
- *Aspectos:* modularizan las preocupaciones transversales (logging, métricas, checkpointing, validación, manejo de excepciones, profiling, hyperparameter tuning, paralelismo/distribución, seguridad, monitorización, repetición/rollback).  

Esto permite que el servicio central permanezca limpio y enfocado, mientras las políticas no funcionales se inyectan mediante weaving sin contaminar la lógica.

---

## 3. Componentes / Clases principales 

- *LinearModel*  
  - Estado: $$w, b$$  
  - Métodos: predict(x) -> y_pred, get_params(), set_params(w,b)

- *Trainer (núcleo)*  
  - Métodos: train(dataset, epochs, learning_rate, batch_size) — implementa el bucle de entrenamiento.  
  - Internals: compute_gradients(batch), apply_update(dw, db, lr)

- *DataLoader*  
  - Método: batches() o get_batch()

- *Validator (opcional)*  
  - Método: evaluate(model, val_set)

- *Config*  
  - Contiene hiperparámetros y políticas (timeout, thresholds).

El *Trainer* es el join point principal donde los aspectos se conectarán.

---

## 4. Join points y Pointcuts 

*Join points relevantes:*
- execution(* Trainer.train(..))
- execution(* Trainer.compute_gradients(..))
- execution(* Trainer.apply_update(..))
- execution(* DataLoader.get_batch(..))
- execution(* Validator.evaluate(..))
- call(* Logger.log(..))

*Pointcuts propuestos:*
- pcTrain = execution(* Trainer.train(..))
- pcEpochEnd = execution(* Trainer.apply_update(..)) && args(dw,db,lr)
- pcComputeGrad = execution(* Trainer.compute_gradients(..))
- pcBatchLoad = execution(* DataLoader.get_batch(..))
- pcOnException = handler(Exception+) && within(Trainer)
